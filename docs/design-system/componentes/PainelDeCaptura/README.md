Popover que abre no ícone do Capta na barra de menus, com as opções da captura e o botão Capturar.

Quem usa fornece as abas ativas (All-In-One, Imagem, Vídeo), o estado de cada opção e o atalho global atual.

- Superfície `superficie-janela`, `raio-painel`, `sombra-painel`, largura de 300 px, preenchimento `espaco-3`.
- Abas com a mesma lógica da barra de ferramentas: ativa em `destaque-fundo` e `destaque`, com peso semibold.
- Opções são interruptores com rótulo em pt-BR; o fundo do interruptor desligado é `borda-controle` (3:1).
- O atalho aparece em `dimensao`; o único botão primário é Capturar.
- Máximo de cinco linhas de opção: o que exigir mais vai para as Preferências.
- Não mostre erro técnico aqui; falta de permissão leva à tela de boas-vindas.
