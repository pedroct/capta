Ativos da marca Capta, todos em SVG e mostrados por `<img>` (sem `currentColor`).

- `capta-simbolo.svg`: o C-moldura em `#14202b` com o ponto em `#ff6b4a`. Para fundo claro.
- `capta-simbolo-claro.svg`: o mesmo símbolo com o C em `#ffffff` e o ponto em `#ff6b4a`. Para fundo escuro ou sobre `marca-ardosia`.
- `capta-icone-app.svg`: ícone do app em tela de 1024 px, corpo de 824 px com cantos arredondados, degradê de `#14202b` para `#17b8a6`, C branco, ponto `#ff6b4a`. É a fonte para gerar o `.icns` e o catálogo de ativos do Xcode.
- `capta-simbolo-barra-de-menus.svg`: versão monocromática em preto, para virar imagem-modelo do ícone da barra de menus.

O logotipo "capta" é composto em Outfit 600, minúsculas; esta versão não traz o logotipo em curvas. Converta o texto em contornos antes de usá-lo fora de um ambiente com a fonte instalada.
